# 📱 BingeWatcher

BingeWatcher is a modern iOS app for discovering, tracking, and managing your favorite manhwa. Built with SwiftUI and powered by the MangaDex API, it delivers a smooth and visually engaging reading companion experience.

---

## ✨ Features

* 🔍 Search and discover manhwa
* 📖 Detailed view with synopsis, rating, and status
* 📚 Personalized “My List” to track favorites
* ⭐ Real-time updates for ongoing series
* 🎨 Clean, modern UI with dynamic gradients

---

## 🛠 Tech Stack

* SwiftUI
* MVVM Architecture
* Combine
* MangaDex API

## 🧠 Architecture

The app follows the MVVM pattern:

* **Model** – Manhwa, Chapter
* **ViewModel** – Handles logic and state
* **View** – SwiftUI UI components
